# ⭐ Featured Projects

## 🔋 STM32 CAN Gateway & BMS Emulator

**STM32F4 • CAN Bus • UART • USB CDC • Qt • Embedded C**

A complete embedded communication architecture designed to simulate and process Battery Management System data through CAN communication.

### Architecture

```text
             ┌──────────────────────┐
             │       Qt GUI         │
             │   BMS Data Monitor   │
             └──────────┬───────────┘
                        │
                   UART / CP2102
                        │
                        ▼
             ┌──────────────────────┐
             │   STM32 CAN Gateway  │
             │      STM32F407       │
             └──────────┬───────────┘
                        │
                     CAN Bus
                        │
                        ▼
             ┌──────────────────────┐
             │   BMS Emulator       │
             │      STM32F407       │
             └──────────────────────┘
```

### Implemented Features

- Extended CAN identifiers
- CAN communication at 500 kbit/s
- UART communication with Qt
- USB CDC debugging
- BMS frame generation
- CAN frame reception
- Data decoding
- Physical-value conversion
- Real-time communication
- Hardware debugging with LEDs

**Main technologies:** STM32F407, CAN, UART, USB CDC, CP2102, Qt, Embedded C, STM32CubeIDE.
